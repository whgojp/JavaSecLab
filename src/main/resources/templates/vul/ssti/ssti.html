SSTI - Template Engine Injection 

SSTI occurs when untrusted input enters a server-side template parsing context.
This module uses Thymeleaf to demonstrate controllable view name paths.

Vulnerable Scenario: Thymeleaf View Name Injection

  • Controllable return
  • Controllable URL

When an attacker controls the Controller returned view name, Thymeleaf preprocesses expressions.

URL path variables concatenated into view names enter Thymeleaf view resolution.

Tips
Typical audit points are whether returned view names or template paths are user controlled.

Safe Scenario: Fixed View Mapping and Bypassing View Resolution

  • Allowlist
  • HttpServletResponse

Select views through a fixed template allowlist.

Return plain text through HttpServletResponse and explicitly skip view name resolution.
