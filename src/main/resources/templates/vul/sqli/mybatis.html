SQL注入攻击 - MyBatis 

  SQL注入的本质是：不可信输入被拼接进SQL语法结构，导致攻击者改变原SQL语义。MyBatis中的XML、注解SQL和动态SQL片段都需要关注这一点。
  MyBatis是一款半ORM（对象关系映射）框架，它允许开发者通过简单的XML或注解配置，将原生SQL、存储过程以及高级映射映射到Java对象（POJO）。

  #{}：用于绑定“值”，底层走PreparedStatement参数化，适合普通查询条件、LIKE值、IN中的单个元素等。
  ${}: performs SQL fragment replacement and should only be used for controlled table names, column names, sort directions, or similar SQL structures. Direct user input inside ${} is high risk.

tips

                                        

                                
  MyBatis 的 #{} 适合值绑定，不适合列名、表名、关键字、排序方向这类SQL结构。
  ${} is not absolutely forbidden, but it must only be used for controlled SQL fragments after allowlist enumeration.
  ORDER BY ${field} becomes dynamic structure injection if it receives user input directly. The correct approach is field enum mapping.
