SQL注入攻击 - Hibernate 

  SQL注入的本质是：不可信输入被拼接进SQL语法结构，导致攻击者改变原SQL语义。Hibernate中的HQL、原生SQL和动态排序字段同样需要关注。
  Hibernate是一个流行的ORM框架，它提供了多种查询方式，如HQL、Criteria API和原生SQL。虽然Hibernate提供了参数绑定等安全特性，但不当使用仍可能导致SQL注入漏洞。
  修复优先级：查询参数使用setParameter绑定；动态字段、排序方向等SQL结构使用枚举或白名单映射。

  在Hibernate中，SQL注入可能发生在HQL查询、原生SQL查询和动态排序等场景。攻击者可以通过注入恶意输入来执行非授权的数据库操作。

漏洞场景：原生SQL注入

tips
  Hibernate需要同时关注HQL和原生SQL：参数值用setParameter绑定，动态列名、排序方向等SQL结构用枚举映射。
  During testing, observe SQL execution results and backend logs, and distinguish HQL syntax from native SQL syntax.
