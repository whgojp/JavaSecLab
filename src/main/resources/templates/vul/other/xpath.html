Other Vulnerabilities - XPath Injection 

XPath is an expression language for querying XML documents.
XPath injection occurs when user input is concatenated into an XPath expression.

Vulnerable Scenario: Raw XPath Concatenation

Tips 
Similar to SQL injection, a tautology can make the predicate always true.
