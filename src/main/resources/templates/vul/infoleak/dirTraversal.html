Information Leakage - Directory Traversal 

Directory traversal leakage appears in directory listing and file browsing features.

Vulnerable Scenario: Raw Directory Listing

In Java applications, directory traversal is often chained with arbitrary file read vulnerabilities.

Tips
Try /infoLeak/dirTraversal/vul?dir=../ to observe whether traversal can escape the expected static directory.

Safe Scenario: Sensitive Character Filtering

Filter sensitive characters and block '.', ';', '\', and '%'.

Tips
Blacklist filtering is often bypassed through special characters or encoding variants.

Safe Scenario: Directory Boundary Restriction

Check whether the requested directory stays under the configured root directory to prevent directory traversal.

Tips
Choose an allowed root first, then validate the target path with canonical or real path checks.
